## 配置窗口

安装或更新后，在 **AstrBot WebUI → 插件 → 短期共享情绪 → 配置** 打开原生配置窗口。仓库根目录的 `_conf_schema.json` 为该窗口提供中文名称、说明、滑块和模型选择器。修改后点击窗口中的保存按钮，配置按 AstrBot 的插件配置流程生效。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| 启用共享短期情绪 | 开启 | 控制插件是否参与对话 |
| 情绪评估模型 Provider ID | 空，跟随会话 | 从已配置的 Provider 中选择后台模型 |
| 评估图片或表情 | 开启 | 向后台模型附带当前请求前两张图片 |
| 后台检测超时 | 30 秒 | 单次检测最长等待 |
| 检测失败重试间隔 | 30 秒 | 失败后暂停提交检测的时长 |
| 后台待检测消息上限 | 16 条 | 限制待处理队列 |
| 检测结果最长有效时间 | 120 秒 | 淘汰过期的消息与结果 |
| 按时间自动恢复 | 关闭 | 默认让模型决定变化；开启后才使用下列时间恢复参数 |
| 持续对话时保持情绪 | 开启 | 仅旧式自动恢复开启时生效 |
| 停止互动后的空闲时长 | 300 秒 | 超过后进入自然恢复 |
| 情绪强度半衰期 | 300 秒 | 自然恢复时强度减半速度 |
| 最长自然恢复时间 | 1200 秒 | 每种情绪恢复为平稳的累计期限 |
| 久别开场允许模型自由选择心境 | 开启 | 后台读取久别背景和偏好，前台只读取结果 |
| 随机心境等待时间 | 21600 秒 | 默认全局停聊 6 小时，重启保留计时 |
| 久别开场心境轻重参考 | 0.3 | 提供给模型的偏好，不是上限或随机区间 |
| 久别后的候选心境 | 平稳、开心、好奇、俏皮、恶作剧、迷糊、疲惫、无聊、烦躁、失落、惬意、期待、犹豫、斗志 | 支持中英文情绪名和常用别名，模型自由决定；已有列表保留 |
| 情绪敏感度 | 1.0 | 调节刺激的影响幅度 |
| 允许自主表达不愿意或拒绝 | 开启 | 允许角色结合当前感受直接拒绝或表达边界 |
| 情绪表达鲜明程度 | 1.0 | 较低更含蓄，较高表现更明显 |
| 日常聊天气质 | 随性自然 | 可选随性自然、活泼外露、含蓄细腻 |
| 玩心与接梗意愿 | 0.6 | 调节关系允许时的接梗、打趣、轻怼和嘴硬 |
| 情绪余韵与惯性 | 0.35 | 调节已有强烈心境被改变时的缓和速度 |
| 补充情绪表达偏好 | 空 | 如“生气时直说，亲近时多逗趣，少写动作描写” |
| 人格表达缓存期限 | 604800 秒 | 默认七天，到期后台重新生成 |
| 命令前缀 | `/`、`!` | 跳过对应命令的情绪处理 |

每条被处理的普通对话会额外产生一次后台模型调用。人格表达每次最多补齐 8 条，优先平稳和当前情绪，完整缓存后只做情绪评估；所有情绪都有即时引导。前台无需等待后台完成，但使用同一个模型服务时仍共享服务端并发和额度。可在窗口中选用独立的检测 Provider。默认图片评估开启，需要评估模型支持图片。

检测失败、超时或输出无效时，默认保留当前心境，只有显式开启旧式自动恢复时才按时间淡化，等待配置的重试间隔后再检测新消息。关闭 `enabled` 可暂停整个插件，关闭 `enable_refusal` 可保留情绪表达并停止直接拒绝提示。

升级到 0.11.0 会保留已有情绪、恢复时间、模型、候选池和开关设置，新增项采用默认值。人格表达缓存会在后台逐步更新为 36 种情绪与平稳状态，部分生成结果也会持久化，重启后继续补齐。修改补充表达偏好后会自动重新生成。新增的 `natural_recovery_enabled` 默认关闭，原有半衰期等参数保留，显式开启后才生效。旧的 `refusal_threshold`、`refusal_probability` 和 `refusal_cooldown_seconds` 继续停用。

## 更多心境与久别后的变化

新增 `playfulness`（俏皮）、`mischief`（恶作剧）、`confusion`（迷糊）、`boredom`（无聊）、`surprise`（惊讶）、`irritability`（烦躁）。这些状态可以与原来的十种情绪混合，由后台根据新互动评估；首次人格提示尚未生成时也有对应的即时表达引导。

0.9.0 进一步扩展下列 12 种心境，可通过 `/mood_set <名称> <强度>` 调试，也可加入随机池。

| 英文键 | 中文名 | 表达方向 |
| --- | --- | --- |
| `anticipation` | 期待 | 想知道进展，设想接下来的互动 |
| `longing` | 想念 | 多留一句、关心近况、嘴硬着欢迎回来 |
| `relief` | 释然 | 紧绷松开、语气舒展 |
| `contentment` | 惬意 | 慢慢聊、安静陪着，也接受“放松” |
| `hesitation` | 犹豫 | 换个措辞、确认一点，也接受“纠结” |
| `jealousy` | 吃醋 | 关系允许时酸一句、承认有点在意 |
| `frustration` | 挫败 | 吐槽不顺，决定重试或歇歇 |
| `guilt` | 内疚 | 对可见过错认错、想补救 |
| `gratitude` | 感激 | 具体接住好意、自然道谢 |
| `admiration` | 欣赏 | 具体夸一句、想了解对方怎么做到 |
| `determination` | 斗志 | 想再试试、提出下一步，也接受“不服气” |
| `tenderness` | 心软 | 保留余气但愿意给台阶 |

“思念”对应想念，“安心”对应释然，“犯迷糊”对应迷糊，“开玩笑”对应俏皮，“调皮”对应恶作剧。命令和随机候选池都接受这些别名、首尾空格以及英文大小写。

想念、吃醋和内疚需结合当前关系与事实理解，不会仅因出现第三人就必定吃醋，也不要求角色凭空认错。前台不参与评估或切换，只沿用已保存的底色。全局共享的是情绪，不会据此把其他会话的具体对象、亲密关系或过错带进当前聊天。混合和切换由模型自由描述，没有宿主选择的固定组合、固定顺序或按回合衰减。敏感度和惯性是偏好参考，宿主直接保存模型的完整决定，旧格式增量也不再额外缩放或加惯性。

0.10.0 再新增 `amusement`（忍俊不禁）、`sulking`（闹别扭）、`absorption`（入迷）、`nostalgia`（怀念）、`skepticism`（将信将疑）、`exasperation`（无奈）、`competitiveness`（好胜）、`awkwardness`（尴尬）。别名包括憋笑、别扭、着迷、怀旧、半信半疑、哭笑不得、想赢、社死。

`random_mood_on_return`、`random_mood_after_seconds`、`random_mood_strength`、`random_mood_pool` 保留旧配置键，但含义改为久别开场机会、间隔、轻重偏好和候选参考。默认全局停聊 6 小时后只把背景交给模型，不执行随机抽签、固定幅度或强制重置；已有心境也交给模型一起判断。连续聊天不会每轮重复附加开场背景。

候选可填写 `["俏皮", "忍俊不禁", "惬意", "迷糊", "平稳"]`，支持全部 36 种情绪及别名。列表仅作偏好，模型仍可按当前语境选择其他合适的感受或继续原来的心情；不会按等概率抽取。重复项去重、无效项忽略，全部无效时使用默认参考。候选与时间配置在升级时保留，且只发送给后台模型，不进入聊天提示。

玩心参数是表达偏好，不是每轮固定触发的概率。角色可以主动抛梗、短暂卖关子、故意听岔再揭梗，烦躁时可以有锋芒；对方认真求助、难过或不喜欢时会被引导收住。迷糊只影响聊天表现，不要求答错事实、编造经历或弄错实际操作。

## 拟人插件联动

`interop_enabled` 默认开启，自动发现可用同伴；关闭后独立使用。前台只读取状态与排队，感受评估在后台完成。详见[四插件联动](LINKING.md)。

## 现实时间感与旧话题

`time_awareness` 默认开启。`context_fade_minutes` 默认 30 分钟，`context_set_aside_hours` 默认 6 小时，`time_preferences` 可写角色习惯。均可在配置窗口修改。原历史保留，新的情绪评估从本次交流接起；Codex 回报不会续期。详见[聊天里也有现实时间](TIME_CONTEXT.md)。

## Codex 内部报告的回应意愿

`allow_codex_notice_refusal` 默认开启，跟随 `enable_refusal`。主模型可对内部报告表达不愿意，支持工具调用时可用 `mood_ignore_codex_notice` 静默放下。用户尚未看到原始报告，向用户说话时会自然带出背景。任务结果保留，不额外排队重播，也不增加前台情绪评估等待。详见[内部收件与情绪回应](MESSAGE_FLOW.md)。

## 0.11.0 前后台职责

情绪评估、完整状态更新、久别候选处理和可选自动恢复都在后台队列完成，前台直接读取内存快照。旧 `emotion_first`、`react_to_current_message` 停用并从配置页移除，已有值会保留但不再生效。前台不再改写系统提示，也不注入评估格式、切换路线或久别选情绪指令。当前消息的情绪评估完成后影响后续回复。
