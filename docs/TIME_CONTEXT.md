# 聊天里也有现实时间

[返回首页](../README.md) · [配置说明](CONFIGURATION.md)

模型的历史记录是一段连续文本，但人可能已经睡了一觉、出过门，或者忙了几个小时。时间感让角色有机会把之前的零碎情绪和话题放下，再接住眼前的人。

默认开启，按当前群或私聊记录真实交流时间，不用额外选择模型：

| 配置窗口项目 | 默认 | 体验 |
| --- | --- | --- |
| 像人一样感受现实中的聊天间隔 | 开启 | 让模型知道上次真实交流距今多久 |
| 隔多久旧话题开始淡下来 | 30 分钟 | 小争执、打趣、告别和临时心情不必一直像刚发生 |
| 隔多久可以先放下旧上下文 | 6 小时 | 可以从现在的新话题重新相处，不必继续演旧气氛 |
| 它对时间间隔的小习惯 | 空 | 可写隔夜不纠结小事，但记得重要约定等偏好 |

例如，昨天临时闹了点别扭，今天说“早呀”，它可以按现在的关系自然接话，不必继续回答昨天的最后一句。用户说“昨天那个话题我还想聊”，又可以自然想起或问两句。具体怎样表达，由模型和主提示词决定。

## 旧记录怎样使用

原始历史继续保留。前台会收到实际时间与新旧聊天阶段的提示，让模型把较早细节当作背景，需要时再回想。这里模拟的是注意力和临场感的变化。

后台情绪评估与相处反思使用新阶段的对话，避免旧争执在每次用户回来时反复增加生气。重新开始聊天后的几轮也会延续这个边界，不会下一句话就把旧刺激重新捞回来。

当时间不足以确认时，不会凭空编造过去了多久。已有 AstrBot 会话的更新时间可作为首次使用时的参考；之后按实际交流计时。每个会话分别记时间，同一个智能体的心情仍然全局共享。

角色的重要关系、长期记忆、约定和正在办的任务可继续存在。时间提示不要求角色按固定台词表现健忘，也不规定遇到旧话题必须拒绝。

## 和其他插件一起使用

Codex 后台回报会带任务来源，它不是用户回来聊天；主动发消息也不会把用户的空闲时间归零。陪它玩的真实互动会计入交流。自娱自乐的相处反思会接住新阶段，保留熟悉感，减少旧临场细节的干扰。

配置改动可在插件窗口完成。关闭时间感后，继续沿用原来的对话上下文与短期情绪行为。所有判断和状态快照都在本地即时完成，不会为时间感额外等待模型。
