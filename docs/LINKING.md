# 四个插件，一起过日子

[返回首页](../README.md) · [配置说明](CONFIGURATION.md)

它的心情、玩心、相处印象和手头的事情可以连起来。每个插件都能单独用；同时启用时自动发现彼此，不需要额外安装联动中心或填写接口地址。

| 插件 | 给同一个智能体补上什么 |
| --- | --- |
| [短期共享情绪](https://github.com/1972124398/astrbot_plugin_short_term_mood) | 同一个心情贯穿所有群聊和私聊，也会从游戏和见闻中产生新感受 |
| [自娱自乐](https://github.com/1972124398/astrbot_plugin_self_amusement) | 记住和谁相处愉快、共同兴趣和最近主动说过的话，闲下来决定聊什么或玩什么 |
| [陪它玩](https://github.com/1972124398/astrbot_plugin_play_together) | 记住正在玩的一局、公开结果和一起玩的余韵，让玩耍成为相处的一部分 |
| [Codex Bridge](https://github.com/1972124398/astrbot_plugin_codex_bridge) | 知道当前会话委托的任务在排队、进行或已经结束，让工作进展回到原本的聊天中 |

## 会怎样联动

- 玩了一局后，模型可以觉得开心、不服、得意、意犹未尽或没什么感觉。由人格、对话和结果决定，不固定规定赢就高兴、输就生气。
- 游戏里直接发数字、出拳等快捷互动也会进入后台的情绪与相处评估。普通聊天中的自然玩法会接着原对话记住新的结果。
- 和某个人玩得来，会影响以后是否想找它聊天或再玩。对方不接话时，邀玩和搭话会互相知道，不会换个插件继续催。
- 自娱自乐可以自己想到找对方玩一局，把这个念头交给陪它玩。只有目标会话也允许陪它玩主动邀请时才会采用这个行动；自娱自乐配置中的“闲下来时也可以想到找人玩一局”可单独关闭。
- 上网闲逛取得的见闻，可以让后台模型产生好奇、兴趣或其他感受。主动开口时会带着最新心情和双方的相处背景。
- Codex 的任务进度、结果仍交给 AstrBot 原本的模型与人格接住。等任务时想继续聊、先玩一局还是歇着，交给模型顺着情境发挥。

心情属于同一个智能体，所以可以从一个会话带到另一个会话。游戏进度、具体聊天印象和任务资料会以当前会话的背景提供，角色不必突然向另一个人讲起它没参与过的事情。

## 配置一次即可自然使用

各插件的配置页都提供 **与其他拟人插件自然联动**，默认打开。没有安装的能力会自动略过，关闭此项则继续使用这个插件原有的独立功能。

自娱自乐、陪它玩和 Codex Bridge 另有 **联动时两次主动开口至少隔几分钟**，默认 10 分钟。每个主动插件按自己的配置，参考共用的最近主动开口时间；设为 0 可取消额外等待。各插件原有的空闲时间、主动目标和时段配置继续有效。

正常聊天、主动邀请和游戏轮次会共用当前活动状态。有人正在聊天、模型正在调用工具，或一局游戏正在进行时，闲聊与新邀约会先缓一缓。暂停游戏后可以继续自然闲聊；主动消息的间隔不会妨碍用户随时聊天或出招。

建议把四个插件都更新到支持联动的版本：

| 插件 | 本轮联动版本 |
| --- | --- |
| Codex Bridge | 2.6.0 |
| 陪它玩 | 0.3.2 |
| 自娱自乐 | 0.4.2 |
| 短期共享情绪 | 0.7.0 |

只装其中任意一个或几个都可以。旧版短期情绪仍可提供基础心情读取，完整的双向互动需要本轮版本。卸载、停用或热重载任意插件后，其余插件继续使用仍存在的能力。

## 后台怎样接住这些感受

前台只收集一份短小的状态和经历快照，情绪评估、相处反思、浏览和主动邀约仍在后台运行，不会等评估完成后才回复。新感受会逐渐影响下一轮和之后的对话。

联动只提供生活背景、实际发生的结果和可用能力。是否开玩笑、是否想继续、怎样接话，由模型和主提示词发挥。Codex 事件会保留后台来源，不会被当作用户本人回了消息，也不会自动变成新的用户任务。

## 给后续扩展

每个仓库自带同一份 `interop.py`，协议版本为 1，不需要额外 Python 依赖。插件通过 AstrBot 的注册表发现同伴，通过以下两个可选方法交流：

- `companion_snapshot(origin)`：读取当前心境或当前会话的公开活动背景。
- `companion_observe(packet)`：接收一次实际经历，只排队后台处理，不同步调用模型。

主动行为共用 AstrBot Context 上的一份临时活动状态，避免两个调度器同时想好并发出消息。游戏、心情、印象和任务的长期保存仍由各自插件负责。热重载释放当前实例的活动状态，不需要创建额外服务或共享数据库。

后续增加小游戏、兴趣活动或新的情绪来源，可以继续发送经历快照，沿用已有的后台反思，不必再制定一套情绪加减分规则。

## 任务来源与现实时间

Codex 回报使用 `w1_event` 标记，`type=task_event`、`is_user_message=false`、`counts_as_user_activity=false`。正文与历史也保留任务来源。其他插件可以直接读取这些字段，不必从任务内容里猜是谁在说话。

短期情绪 0.7.0 增加当前会话的现实时间感，默认 30 分钟后淡化旧话题、6 小时后可以先放下旧细节。后台回报不会被记成真实用户活动，旧任务资料也不会送去评估用户对它的态度。相处反思会从这次新的聊天阶段接起。原历史可由模型按当前意图回想。

## 内部报告也可以先不理

Codex 发给 AstrBot 的是内部报告，用户尚未见过原文。是否转述、怎样开口，由 AstrBot 的主模型结合心情决定。静默放下时 `w1_notice_disposition.action=ignore`，各插件不把它记为已发出的聊天。任务结果仍保留。查看[内部收件与情绪回应](https://github.com/1972124398/astrbot_plugin_codex_bridge/blob/main/docs/MESSAGE_FLOW.md)。
