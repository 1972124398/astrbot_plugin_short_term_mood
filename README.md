## 聊天体验

- 开心时更热情，好奇时想接着问，疲惫时可能少说几句。
- 熟人间可以接梗、轻怼或嘴硬，也可以坦率承认高兴。
- 生气、委屈与不愿意可以直接表达，得到关心后逐步心软。
- 俏皮时主动抛梗，恶作剧时故意逗一下再揭梗，迷糊时自己改口或确认一句。
- 无聊时想找点乐子，惊讶时愣一下，烦躁时可以吐槽或回怼。
- 期待时忍不住问进展，想念时多留一句，惬意时慢悠悠地聊；吃醋时可以酸一下，心软时可以带着余气给台阶。
- 有挫败也可以不服输，收到好意可以感激又不好意思，犹豫或内疚也可以坦露一点。
- 忍俊不禁时自己先破功，聊入迷时兴致勃勃，好胜时想再来一局，尴尬时也能自嘲化解。
- 心境的延续、混合与切换由大模型根据人设和互动决定，久别后的心境也在后台自由变化。
- 私聊、群聊和不同人格共享一份心境，各人格保留自己的措辞。

支持 **36 种情绪**混合，以及最近五次抽象心境的连续变化。玩笑会随对方反应收住，迷糊体现在说话中，事实回答与工具操作仍然认真。

| 互动 | 实际生成片段 |
| --- | --- |
| 善意叫它“小笨蛋” | “反正你也没聪明到哪去。” |
| 被认真道歉 | “刚才那几句确实挺扎人的。” |
| 后续被认真倾听 | “你能这么讲我气消大半。” |

片段来自模拟人格的连续聊天，实际措辞随人设、模型和对话变化。

## 快速开始

需要 **AstrBot `>=4.29.4,<5`、Python 3.12+**，并已配置可用的聊天模型。

1. 在 AstrBot 插件管理中使用下方仓库地址安装，或下载 ZIP 后从文件安装。
2. 打开 **插件 → 短期共享情绪 → 配置**。
3. 保留默认配置开始聊天，也可选择独立的情绪检测模型。
4. 使用 `/mood` 查看当前共享心境。

```text
https://github.com/1972124398/astrbot_plugin_short_term_mood
```

安装与更新支持自动加载或单独重载。首次遇到一份主提示词时，会在后台生成人格化的表达提示。

## 常用配置

| 配置 | 默认体验 |
| --- | --- |
| 聊天气质 | 随性自然，可选活泼外露或含蓄细腻 |
| 玩心与表达 | 玩心 `0.6`，表达强度 `1.0`，情绪惯性 `0.35` |
| 持续聊天 | 保留心境，当前消息可立即引起表达上的反应 |
| 情绪切换 | 模型决定本轮完整心境，插件保存结果；可以渐变、保留余韵，也可以被强烈刺激明显改变 |
| 空闲恢复 | 默认由模型结合真实时间判断；按时间自动衰减保留为可选旧机制 |
| 久别后的心情 | 全局停聊 `21600` 秒（6 小时）后，向后台模型提供一次久别开场参考 |
| 开场偏好 | 候选心境与强度 `0.3` 都是参考，具体选择交给模型，也可以继续旧心情 |

在配置中填写表达偏好，例如“亲近时多逗趣，生气时直说，少写动作描写”，可以进一步调整口吻。

<details>
<summary><strong>支持哪些情绪？后台检测如何影响聊天？</strong></summary>

支持开心、亲近、失落、生气、不安、疲惫、好奇、害羞、得意、委屈、俏皮、恶作剧、迷糊、无聊、惊讶、烦躁、期待、想念、释然、惬意、犹豫、吃醋、挫败、内疚、感激、欣赏、斗志、心软、忍俊不禁、闹别扭、入迷、怀念、将信将疑、无奈、好胜、尴尬。模型决定当前保留哪些感受，以及哪些露出来、哪些只作底色。

俏皮偏向开玩笑和接梗，恶作剧偏向故意逗人、短暂卖关子再揭梗；烦躁是耐心少了，不一定有人惹它。它可以亲近又想恶作剧、疲惫又迷糊、烦躁但仍愿意陪着。

模型可在自由描述的余韵和互动倾向中表达复杂心境，例如想念又委屈、期待又紧张、生气但心软。例子只供启发，没有代码选择的固定搭配、切换路线或回合衰减。后台可以保持原有感受、慢慢松动、转向新感受；前台只沿用已有底色自然接话。

久别开场默认参考包括平稳、开心、好奇、俏皮、恶作剧、迷糊、疲惫、无聊、烦躁、失落、惬意、期待、犹豫、斗志、忍俊不禁、入迷，已有候选列表保持原配置。列表和轻重都是偏好，后台模型可以结合眼前消息选一种，也可以平稳、延续旧心情或作其他合适反应；脚本不抽签、不替模型定心情。计时按所有会话最后一次真实互动保存，命令、后台报告和主动发言不会续期。

前台只读取后台已经保存的心境作为简短的说话底色，不选择情绪、不参与评估，也不等待网络或数据库。后台检测完成后，变化从后续回复开始自然体现。

所有心境都有轻量表达参考。人格专属提示在普通后台评估中每次最多补齐 8 条，优先当前情绪，后续聊天逐步补齐并缓存，减少首次要求一次生成全部提示的输出量。

普通对话会额外产生一次后台模型调用。使用同一服务时共享并发和额度，可选择独立 Provider。默认会评估图片，检测模型需支持图片，也可以关闭图片评估。

## 命令

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/mood` | 所有人 | 查看共享心境、余韵和互动倾向 |
| `/mood_reset` | 管理员 | 恢复平稳 |
| `/mood_set 生气 0.8` | 管理员 | 设置情绪以调试，也支持英文名称 |
| `/mood_refresh` | 管理员 | 清除人格表达缓存，下次后台重新生成 |

也可用 `/mood_set 恶作剧 0.5`、`/mood_set 迷糊 0.4`、`/mood_set 烦躁 0.5` 体验不同心情。命令只设置心境，具体怎么接话仍由人格、模型和眼前情境决定。

新心境可试 `/mood_set 期待 0.5`、`/mood_set 想念 0.4`、`/mood_set 心软 0.5`，也支持“放松”“思念”“犯迷糊”“不服气”等常用别名和英文名称。

## 常见问题

<details>
<summary>情绪表达太淡、太明显，或第一次聊天变化不大</summary>

首次检测和人格表达生成需要后台完成。可通过 `/mood` 查看心境，再调整表达鲜明程度、聊天气质和表达偏好。

</details>

<details>
<summary>持续聊天一直有情绪，或希望减少拒绝</summary>

默认由模型判断什么时候继续、缓和或放下心境，停聊不会被脚本自动改成平稳。需要旧式自动恢复时，可开启“使用按时间自动恢复的可选旧机制”。关闭“允许自主表达不愿意或拒绝”后，仍可保留其他情绪表达。

</details>

<details>
<summary>后台检测失败，或微信底层 API 报错</summary>

先检查 Provider、图片支持、超时配置和插件日志。微信 API 返回 HTTP 500 等环境问题，见 [兼容与排错](docs/COMPATIBILITY.md)。

</details>

## 隔了一段时间，再自然相处

聊天记录连着，人可能已经隔了半天。现在可以让它淡化旧话题、放下零碎临场细节，再接住眼前的人；用户想续聊时仍可回想。默认 30 分钟开始淡化、6 小时可以先放下，配置页可改。查看[时间感说明](docs/TIME_CONTEXT.md)。

## Codex 发给它的内部报告

用户还没有看到 Codex 的原始报告。它可以结合人格与心情决定是否告诉用户，也可以先不理；任务与结果继续保留。查看[内部收件与情绪回应](docs/MESSAGE_FLOW.md)。

### Windows 旧开发目录覆盖安装失败

上传 ZIP 时若出现 `Cannot call rmtree on a symbolic link`，说明旧插件目录是 Junction／目录链接，AstrBot 在加载插件之前就无法替换目录。需要先将该目录链接恢复为普通插件目录，再安装 ZIP；不要删除链接指向的源码仓库或插件数据目录。正常通过 ZIP 安装的目录无需处理。0.11.2 已补充旧版 ZIP 覆盖升级、配置和心情保留的实际安装测试。
