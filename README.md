# AstrBot 短期共享情绪

[![版本](https://img.shields.io/github/v/release/1972124398/astrbot_plugin_short_term_mood)](https://github.com/1972124398/astrbot_plugin_short_term_mood/releases/latest)
[![测试](https://github.com/1972124398/astrbot_plugin_short_term_mood/actions/workflows/test.yml/badge.svg)](https://github.com/1972124398/astrbot_plugin_short_term_mood/actions/workflows/test.yml)
[![许可证](https://img.shields.io/badge/license-0BSD-blue)](LICENSE)

给 AI 增加一份跨对话共享的短期心境，让它在聊天里有开心、害羞、玩心、小脾气和逐渐缓和的情绪余韵。

受到关心时更愿意亲近，被冷落时可能有些委屈，得到道歉和照顾后也会慢慢心软。表达结合原有人格、眼前的话题与当前心境生成。

[快速开始](#快速开始) · [配置参考](docs/CONFIGURATION.md) · [兼容与排错](docs/COMPATIBILITY.md) · [工作方式](docs/DEVELOPMENT.md) · [更新记录](CHANGELOG.md)

## 聊起来会有什么变化

- 开心时更热情，好奇时想接着问，疲惫时可能少说几句。
- 熟人间的善意打趣可以接梗、轻怼、嘴硬，也可以坦率承认高兴。
- 生气和委屈可以直接表达，角色也能说出不愿继续的话题。
- 情绪可以混合，亲近又有点别扭、开心又害羞都有表达空间。
- 保留最近五次抽象心境变化，前后回复有连续的缓和与转变过程。
- 私聊、群聊和不同人格共享同一份心境，各人格用自己的措辞表达。

连续模拟聊天中的真实生成片段如下。

| 互动 | 回复片段 |
| --- | --- |
| 善意叫它“小笨蛋” | “反正你也没聪明到哪去。” |
| 被认真道歉 | “刚才那几句确实挺扎人的。” |
| 后续被认真倾听 | “你能这么讲我气消大半。” |

片段来自指定模拟人格和模型，实际措辞会随人设、模型与对话变化。

## 快速开始

需要 **AstrBot `>=4.29.4,<5`、Python 3.12+**，并已配置可用的聊天模型。

1. 在 AstrBot 插件管理中通过下方仓库地址安装，或下载发布页的 ZIP 后从文件安装。
2. 打开 **插件 → 短期共享情绪 → 配置**。
3. 保留默认配置即可开始聊天，也可选择独立的情绪检测模型。
4. 发送普通聊天消息，使用 `/mood` 查看当前共享心境。

```text
https://github.com/1972124398/astrbot_plugin_short_term_mood
```

[下载安装包](https://github.com/1972124398/astrbot_plugin_short_term_mood/releases/latest/download/astrbot_plugin_short_term_mood.zip)

安装与更新支持自动加载或单独重载。首次遇到一份主提示词时，会在后台生成人格化的情绪表达提示。

## 默认体验

| 配置 | 默认值 | 体验 |
| --- | --- | --- |
| 日常聊天气质 | 随性自然 | 允许短句、接梗、感叹和自然接话 |
| 玩心与接梗意愿 | `0.6` | 关系允许时更愿意打趣和轻怼 |
| 情绪表达鲜明程度 | `1.0` | 按当前情绪强度表现 |
| 情绪惯性 | `0.35` | 强烈心境有逐渐缓和的过程 |
| 当前消息即时反应 | 开启 | 这一轮就可以表现对当前消息的感受 |
| 持续聊天保持情绪 | 开启 | 对话活跃时保留当前心境 |
| 停聊后的空闲时间 | `300` 秒 | 之后进入自然恢复 |
| 自然恢复半衰期 | `300` 秒 | 恢复期间每五分钟强度减半 |
| 最长自然恢复时间 | `1200` 秒 | 累计达到后恢复平稳 |

支持开心、亲近、失落、生气、不安、疲惫、好奇、害羞、得意、委屈十种情绪。多种情绪可同时存在，主要取最强的三种影响当前表达。

配置窗口还可以选择“活泼外露”或“含蓄细腻”，以及填写自己的表达偏好，例如“亲近时多逗趣，生气时直说，少写动作描写”。

[全部配置与升级说明](docs/CONFIGURATION.md)

## 前台等待与模型调用

前台直接使用已有心境，并允许聊天模型即时回应当前刺激。后台检测完成后，会把心境变化延续到后续对话。

普通对话会额外产生一次后台模型调用。使用同一服务时会共享并发和额度，可在配置中选择独立 Provider。默认会评估图片，请为情绪检测选择支持图片的模型，或关闭图片评估。

## 命令

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/mood` | 所有人 | 查看共享心境、余韵和互动倾向 |
| `/mood_reset` | 管理员 | 恢复平稳 |
| `/mood_set 生气 0.8` | 管理员 | 设置情绪以调试，也支持英文情绪名称 |
| `/mood_refresh` | 管理员 | 清除人格表达缓存，下次后台重新生成 |

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 第一次聊天还没有明显变化 | 后台需要先完成检测和人格表达生成，可用 `/mood` 查看 |
| 情绪表达太淡或太明显 | 调整“情绪表达鲜明程度”、聊天气质和表达偏好 |
| 不想直接拒绝用户 | 关闭“允许自主表达不愿意或拒绝”，仍可保留其他情绪表达 |
| 聊天一直有情绪 | 默认活跃期间保持，停聊超过空闲时间后恢复；可关闭持续保持 |
| 后台检测失败 | 检查 Provider、图片支持、超时配置及插件日志 |
| 微信底层 API 返回 HTTP 500 | 查看 [Windows 原生微信运行环境说明](docs/COMPATIBILITY.md#windows-原生微信运行环境) |

已有插件的集成方式与范围见 [兼容说明](docs/COMPATIBILITY.md)。
